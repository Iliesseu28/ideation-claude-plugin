# Ideation plugin for Claude Code

Lets your Claude keep your [Ideation](https://simplibot.fr) project up to date: build journal, to-dos, documents, roadmap, release notes.

```
/plugin marketplace add Iliesseu28/ideation-claude-plugin
/plugin install ideation@ideation
```

Paste your account key (`idn_...`, created in the Ideation app: Settings, Claude Code) when asked, then check with `/mcp`.

On claude.ai, Claude Desktop or the Claude mobile app, add a custom connector instead: `https://ideation-dd18f.web.app/mcp`.
